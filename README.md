This is my personal portfolio website, built for ISDS 3100 (Information Systems Foundations, Fall 2026) at LSU by vibe coding with Google Antigravity IDE. It has a single-page profile (about, skills, experience, contact) plus separate Resume and Project pages, written in plain HTML and CSS and hosted on GitHub Pages.

**Live site:** https://camerronxo.github.io/CameronTurner-Natural_Intelligence--ISDS/

## Reflection

I didn't understand why my repository showed four empty files when my commit messages said that I have added styling, pages, and a README. I asked an AI assistant why the commits had no content, and learned that Git only commits what is saved on disk at that moment, so files still unsaved in the editor were committed empty. After figuring this out I decided to save all files before running `git add .` and check each commit on GitHub to make sure the changes are actually there. With this it finally created the website with the factors that I personally wanted to include.
