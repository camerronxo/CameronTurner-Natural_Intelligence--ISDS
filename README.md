## Reflection

I didn't understand why my repository showed four empty files when my commit messages said I had added styling, pages, and a README. I asked an AI assistant why the commits had no content, and learned that Git only commits what is saved on disk at that moment, so files still unsaved in the editor were committed empty. Now I save all files before running `git add .` and check each commit on GitHub to make sure the changes are actually there.
