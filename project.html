Building this site with an AI agent

A vibe coding project for ISDS 3100 · Fall 2026

The goal

Build a professional, recruiter-facing website without a site builder: real HTML and CSS files that I own, can inspect, and keep under version control. An AI agent wrote the code; my job was to specify what I wanted, review what it produced, and decide when it was good enough.

The managerial skill here isn't typing code. It's being precise about what a system should do and judging whether the output actually does it.

Tools

  • Google Antigravity IDE for prompting the agent and reviewing every file it created
  • Git to track each change, with commits spread across the build
  • GitHub as the public repository and remote backup
  • GitHub Pages to host the live site for free

How I built it

  1. Set up the skeleton. Created four files (index, resume, project, styles) so every page shares one stylesheet and stays consistent.
  2. Wrote the content. Replaced the agent's generic filler with my real background, skills, and experience.
  3. Designed the look. Chose a navy and white palette with a gold accent, one typeface, and a sticky navigation bar that works on every page.
  4. Made it responsive. Tested at phone width and adjusted the layout so nothing scrolls sideways.
  5. Deployed and tested. Published with GitHub Pages and checked every link on the live site in more than one browser.

What went wrong, and what I learned

After several commits, I checked my repository on GitHub and found that four of my five files were completely empty, even though my commit messages described styling, pages, and a README. The site looked finished in my head but not on GitHub.

When I asked an AI assistant why, I learned that Git only records what's saved on disk at the moment you commit. If a file is still unsaved in the editor, Git commits the empty version and the message has nothing to do with what's actually inside. Now I save every file before committing and open each commit on GitHub to confirm the changes are really there.
